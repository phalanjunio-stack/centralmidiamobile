# Contourline Backup — Icon Pack

Pacote com ícones individuais em SVG e PNG transparente.

## Pastas
- `svg/`: ícones vetoriais individuais.
- `png_512/`: PNG transparente 512x512.
- `png_128/`: PNG transparente 128x128.
- `footer_svg/`: rodapé/bottom navigation completo em SVG.
- `footer_png/`: rodapé/bottom navigation completo em PNG.
- `preview/`: prancha de prévia.

## Rodapé principal
Itens: Início, Projetos, Câmera, Galeria, Upload.
A câmera é o botão central flutuante em azul.
Arquivos especiais incluem estados de Upload com fila, enviando e erro.

## Correção
`configuracoes_gear` e `configuracoes_camera` usam engrenagem.
`exposicao` é o sol/controle de clarear e escurecer.
